# Assets Directory

This directory contains static assets for the project documentation.

## Screenshots

The `screenshots/` folder is designated for application screenshots used in the main README.md file.

### Screenshot Guidelines

#### Recommended Screenshots to Capture:
1. **login.png** - Login page showing the modern UI design
2. **register.png** - Registration page with role selection
3. **farmer-dashboard.png** - Farmer's main dashboard view
4. **employee-dashboard.png** - Employee's administrative dashboard
5. **product-list.png** - Product management interface
6. **add-product.png** - Add/Edit product form

#### Best Practices:
- Use consistent browser window size (1920x1080 recommended)
- Capture full page or relevant sections
- Use PNG format for crisp quality
- Keep file sizes reasonable (under 1MB each)
- Use descriptive filenames matching the README references
- Ensure no sensitive data is visible in screenshots

#### How to Add Screenshots:
1. Take screenshots of the running application
2. Save them in the `screenshots/` folder with appropriate names
3. Update the README.md file by uncommenting the image references:
   ```markdown
   ![Login Page](assets/screenshots/login.png)
   ```

#### File Naming Convention:
- Use lowercase letters
- Use hyphens (-) instead of spaces
- Be descriptive but concise
- Include the file extension (.png)

Example: `farmer-product-management.png`
